# MOVE : 이소 — 메타버스 졸업전시 가상 전시장 + 웹사이트 기획서 (gtec001)

작성: 2026-10-23. 사용자 요청: "졸업전시회를 위한 메타버스 형태의 갤러리. 안에 졸업전시 인트로 영상, 부스마다 졸업작품 섹션·작가·작가소개·작품소개. jhong003 방식대로. 홈페이지는 졸업전시 컨셉과 비슷하게, 입구는 졸업전시 분위기, 각 부스는 작가 스타일에 맞춰서. 부스 QR 과 입구 QR 로 휴대폰에서도." 자료 정리: [00_자료정리.md](00_자료정리.md).

## 1. 한 줄 정의

**둥지를 떠나는 밤.** 별하늘 아래 로비에서 세 전시관으로 갈라지는 가상 전시장. 졸업생 42명이 부스 하나씩을 갖고, 부스 색은 각자의 대표작에서 뽑는다. 입구·부스 QR 을 찍으면 휴대폰에서 같은 전시장의 같은 자리로 들어온다.

## 3. 공간 설계 (평면도 = `site/src/lib/layout.ts`)

```
                     북 · 일러스트관 (16 부스, 8+8)
                              │
  서 · 웹툰관 (21 부스, 11+10) ─ 로비(원 r=13) ─ 동 · 출판만화·애니메이션관 (5 부스, 3+2)
                              │
                     남 · 입구 통로 (게이트 · 환영 문구 · 표지 벽)
```

- 로비: 별하늘 돔, 로고 배너(도록 로고), 빨간 우체통, 공중에 떠다니는 편지 180장(인스턴스), 관마다 분야색 아치 표지판.
- 복도 폭 8m, 부스 폭 6.4 × 깊이 4.2 × 높이 4. 천장 없음(밤하늘).
- 부스: 뒷벽 대표작(최대 3.4×2.5m) + 이름표(이름·영문·작품제목·분야색) / 옆벽 작품(웹툰은 세로 스트립 3장씩, 일러스트는 2장씩) / 앞 오른쪽에 **서명+QR 안내판**. 벽색 = 대표작 바탕색을 아이보리 쪽으로 72% 섞은 것(어두운 그림은 어두운 벽), 바닥 = 포인트색을 어둡게, 모서리 기둥 = 포인트색, 상단 띠 = 분야색. 액자색: 웹툰 먹 · 일러스트 아이보리 · 출판만화 검정 · 애니메이션 초록.
- 조작: PC 는 WASD/방향키 + 마우스 드래그, Shift 달리기. 휴대폰은 왼쪽 아래 조이스틱 + 화면 드래그. 작품/이름표/QR 탭 → 오른쪽 패널(큰 그림·썸네일·소개·소감·작가 페이지 링크). 미니맵 클릭·작가 목록 서랍 = 순간이동. 걷기 영역은 로비 원 + 복도 + 부스 안(벽 통과 없음).
- 성능: 텍스처(대표작 1024px, 작품 1024/스트립 1400px)는 카메라 34m 안 부스만 읽고 52m 밖은 버린다(휴대폰 26/40m). 픽셀비 최대 2(휴대폰 1.5).

## 4. 사이트 구조 (정적 · 해시 라우팅)

```
/            홈 — 밤하늘 히어로(표지·제목·기간·입장) → 전시관 4 → 작가 42 카드 → 입구 QR → 인사말
/gallery     3D 전시장 (?booth=id 부스 앞 시작 · 처음엔 인트로)
/booth/:id   부스 QR 착지 → /gallery?booth=id
/intro       인트로(웹 v0 / videos/intro.mp4 있으면 영상)
/artists     작가 목록 + 분야 필터 · /artists/:id 작가 페이지(팔레트 색 히어로, 소개·소감·서명, 웹툰 세로 리더, 작품 격자+라이트박스, 부스 QR, 이전/다음)
/about       인사말 전문 · 축전 10장 · 졸업전시준비위원회 5인 · 서명 모음 · 판권
/qr          인쇄용 QR: 입구 1장(A4 한 면) + 부스 42장(3열). 주소 칸에 배포 주소 입력 후 인쇄
```

## 5. QR 규칙

- QR 은 브라우저에서 생성(`qrcode`), 주소는 **현재 사이트 주소 기준**(`siteBase()`). 로컬 미리보기에서 휴대폰으로 시험하려면 PC 에서 `http://<PC IP>:5201/#/qr` 을 열어 찍는다(그래야 QR 에 IP 가 들어감). 배포 후엔 배포 주소에서 열거나 `/qr` 의 주소 칸에 적는다.
- 입구 QR → `#/gallery`, 부스 QR(인쇄·작가 페이지) → `#/a/<id>`(작가 페이지, 휴대폰에서 글·그림 먼저 → 「3D 부스로 들어가기」), 3D 안 안내판 QR 도 같음.
