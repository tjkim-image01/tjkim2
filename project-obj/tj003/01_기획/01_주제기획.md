# tj003 주제 기획 — 엽서 뒷면 읽어 드립니다: 스코틀랜드의 '코리아 하우스'

선정일: 2026-10-15. 사용자 제안 "tj001 엽서 뒷면에 적힌 이야기를 하나하나 소개하자" → 뒷면 전수 판독(00_뒷면이야기_후보.md) → 사용자 결정 "삐라(tj002)보다 이쪽에 역사가 더 있다. tj003 진행".

## 주제

**엽서 앞면은 풍경, 뒷면은 사람.** 티제이 김 컬렉션의 1920년대 극동 엽서 묶음(APKC230615122, 40여 점)이 **경성 주재 영국 총영사 아서 하이드 레이 집안의 앨범**임을 뒷면 주소로 밝히고, 그 앨범 속 엽서 뒷면을 한 장씩 읽는다. 1914년 경원선 개통 기념 소인 → 1925년 을축년 대홍수 → 1937년 로제타 셔우드 홀의 런던 엽서 → 스코틀랜드 켈소의 "Korea House".

## 선정 근거

| 항목 | 내용 |
|---|---|
| 재료 | tj001 스캔 555장 중 손글씨·소인 뒷면 약 12장. 한국 관련 핵심 4건(EE·GG·I·NN) + 조선호텔 1921 + 외국 발신(1910 프랑스 비행기 5장, 1945 미군 2장, 1995 영국 해군 봉투) |
| 발견 | 수신인 3장이 모두 "British Consulate General, Keijo" 또는 "'Korea House', Kelso, Scotland" → 한 집안. Korea Times(R. Neff, 2024)가 하이드 레이가 은퇴 후 스코틀랜드 집을 "Korea House"라 이름 붙였다고 확인 |
| 이해 난이도 | 설명 없이도 "편지 읽어 주기"라 쉽다. 숫자·연도는 소인이 증명한다 |
| 톤 | 따뜻한 아카이브. 유쾌함은 두 화자의 티키타카와 '읽어 보니 별 내용 없음'(1910 비행기 엽서) 같은 반전에서 나온다 |

## 형식

- 롱폼 1편(16:9, 약 4분): 「스코틀랜드의 코리아 하우스」 — 하이드 레이 집안 앨범 한 줄기(1914 → 1925 → 1937 → Korea House).
- 쇼츠 3편(9:16, 각 50~70초): ① 날지 못한 비행기가 엽서로는 날았다(1910 파리) ② "내일 주소 보낼게"(1945 미군 → 인천) ③ 한 시간에 집 200채(1925 홍수).
- 시리즈 이름 **「뒷면 읽어 드립니다」**. tj001 엔딩("뒷면 이야기는 롱폼에서")을 회수하므로 화자는 tj001의 **태진(현준)·하린(예나)** 그대로.

## 화자

| 배역 | 설정 |

| 태진 (30대 수집가) | 엽서를 뒤집어 뒷면을 읽어 준다. 번역은 담백하게, 추정은 "~로 보여"라고 밝힌다 |
| 하린 (20대 친구) | "그래서 이게 누군데?"를 대신 묻고, 요즘 것에 빗댄다("짤", "DM") |

## 비주얼 방향 (04_제작설계 참조)

실물 뒷면이 주인공. **손글씨가 펜으로 써지듯 드러나는 트레이스**, 영어 원문 위에 한국어 번역이 종이 조각처럼 붙음, 소인·우표·씰이 '쾅' 찍힘, 지도 위 경로선(런던→서식스→엡워스→에든버러 / 북경→천진→봉천→대련→여순→서울), 연표 띠(1887→1902→1914→1927→1937). tj002에서 재기획한 "유쾌·화려" 원칙(큰 활자, 종이 찢기 전환, 캐릭터 4포즈, 효과음, BGM)은 유지하되 색은 아카이브 톤(크림·먹·우체국 빨강·잉크 파랑).

## 핵심 메시지

나라 이름이 공식적으로 '조선'으로 지워진 1930년대에, 조선을 떠난 사람들은 스코틀랜드의 "코리아 하우스"로 편지를 보냈다. 엽서 뒷면에 남은 것은 풍경이 아니라 사람이다.
