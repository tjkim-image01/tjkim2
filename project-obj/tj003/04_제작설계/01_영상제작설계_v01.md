## 비주얼 언어

- **무대**: 크림 종이 `#F4EBDA` + 먹 `#1F2A37` + 우체국 빨강 `#C5392B` + 잉크 파랑 `#1F4E8C` + 금 `#C9A24A` + 씰 초록 `#2F6B4F`. 하프톤 대신 **종이 섬유·얼룩** 질감. 장면마다 색면이 바뀌되 채도는 낮게.
- **손글씨 트레이스(HandReveal)**: 실물 뒷면 스캔 위에 글줄 순서대로 마스크가 펜처럼 지나가며 드러난다(줄별 사각 마스크 + 펜촉 포인터 + 긁힘 효과음). 읽는 대사 타이밍(`cue`)에 줄이 맞춰진다.
- **번역 카드(Translate)**: 영어 원문 한 줄을 드러낸 뒤 그 아래에 한국어 번역이 종이 조각처럼 '툭' 붙는다. 원문은 Nanum Pen, 번역은 NanumSquareRound.
- **소인·우표·씰(Stamp)**: 실물에서 잘라낸 소인·씰을 1.6→1.0 스케일로 '쾅'. 날짜는 Bagel Fat One으로 옆에 크게.
- **지도 경로(Route)**: 단순 윤곽 지도(SVG) 위에 점선이 그려진다. 런던→서식스→엡워스→에든버러 / 북경→천진→봉천→대련→여순→서울→일본 / 용산→원산.
- **연표 띠(Timeline)**: 1887 도쿄 → 1902 제물포 → 1914 서울 → 1927 켈소 → 1937 엽서. 띠가 옆으로 밀리며 해당 연도에 점등.
- **캐릭터**: tj001 태진·하린 스프라이트 재사용 + 포즈 3종(놀람·웃음·가리킴) ChatGPT 추가 생성(같은 종이 콜라주 스타일, STYLE_REF = tj001 STYLE_REF). 말할 때 바운스, 감정별 포즈 교체.
- **전환**: 엽서 뒤집기(3D flip)로 앞면→뒷면, 종이 슬라이드, 앨범 페이지 넘김.
- **엔딩**: 앨범 40장 벽 + "코리아 하우스" 문패.
