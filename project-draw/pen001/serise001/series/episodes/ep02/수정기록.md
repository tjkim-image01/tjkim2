- 앞쪽 남성 → 뒤쪽 여인 → 뒤쪽 남성 → 앞쪽 여인. 각 사람을 얼굴·머리 → 몸·손 → 다리·아랫옷 순서로 완성한다.
- 인물 네 명: 0.8~34.8초. 물건(놀이판·윷): 34.8~41.8초. 배경: 41.8~49.8초. 초기 전체 구도선은 제거했다.
- 자막: 나눔명조 Regular(NAVER/NHN, SIL OFL 1.1). 한 문구 전체를 약 2.4~3.4초 보여 준다. 타이핑·단어 강조·확대·튀는 동작을 제거하고 0.22초 투명도 전환만 사용한다. 내레이션의 속도·음원·음악 믹스는 유지했다.
- 마지막 편집본 오버랩과 TJ KIM 컬렉션 안내, 음악의 하단 출처 표시는 유지했다. 소장 이미지의 AI 정리 편집본이라고 화면에 구분했다.
- 구버전 아트·영상·자막은 versions/before-figure-first/에 보관했다.
- 전체 디코딩, 빈 종이 시작, 순서와 배경 시점, 자막 정지 구간, 오버랩, 모바일 작업실과 단계 버튼을 검증했다. 나머지 아홉 MP4의 SHA-256이 수정 전과 일치한다.

## 자막 18자 수정본

2026-10-25: 1화만 다시 출력했다. 모든 자막을 한 번에 하나의 짧은 완결 문장으로 표시한다. 공백·쉼표·마침표·영문을 포함해 18자를 넘지 않는다(17개, 최대 18자). 해설의 뜻을 짧게 요약한 문장 자막이며 음성 원문을 모두 옮긴 자막은 아니다. 내레이션과 음악은 유지했다.

명조체의 크기를 48→54px로 키웠다. 그림 영역 하단 1176px 아래인 1212px에 자막을 배치했다. 마지막 AI 편집본 설명은 1340px로 옮겨 겹치지 않게 했다. 움직임은 없고 문구 전환 때 0.22초의 투명도 변화만 사용한다. 작업실 편집 입력도 한 줄·18자 제한을 적용한다.

이전 자막·영상·제작 코드는 versions/before-caption-18/에 보관했다. 자막의 글자 수·문장 끝·그림 아래 한 줄 영역·확대 크기·줄 넘침을 전부 검사했고 MP4 전체 디코딩 검증도 통과했다.

## 인물 확대·붓 연출 플레이어 v4

2026-10-25. 사용자 지시에 따라 이번 수정은 실시간 플레이어에만 적용했다. MP4를 출력하지 않았으며 기존 열 MP4의 SHA-256 일치를 확인했다. 영상 파일과 ZIP은 이전 자막 18자 수정본 그대로다.

- 0~1초 빈 종이 정지, 1~3초 힘 있게 휘긋는 한 획의 붓끝을 따라가는 클로즈업, 3~4초 전체 획을 보여 주고 인물 구도로 전환한다.
- 이후 기존 그림을 인물별 얼굴 → 몸·손 → 다리·아랫옷 순으로 그린다. 얼굴은 약 4.2~4.8배, 몸은 약 1.8~3배로 확대하고, 물건과 배경에서 전체 구도로 돌아온다.
- 기존 60초 구성 앞에 도입 4초를 추가한 총 64초 플레이어다. 자막·음성의 시작도 4초 늦춰 맞췄고, 64초 음악을 해설 아래에서 새로 조절했다. 음악의 왼쪽 아래 출처는 유지한다.
- 세필·중필·대필·평붓 네 종류, 각 96개의 서로 다른 3D 자세 PNG(총 384개). 원래 단일 붓 32장에서 늘렸고, 붓대도 조금 길게 만들었다. 선택·각도 변화는 재생 시간에 따라 재현된다. 사용자는 자동 또는 개별 붓을 고를 수 있다.
- 화선지 효과는 실제 유체 해석이 아니라 시각 효과다. 현재 칠한 안료만 얇게 번지고 약 0.9초에 걸쳐 가장자리에 스미도록 했다. 종이 섬유 무늬와 불규칙한 낮은 농도의 가장자리를 사용한다. 스밈 강도는 0~100% 조절·저장할 수 있다. 아직 그리지 않은 부분을 번짐으로 미리 드러내지 않는다.
- 한 줄·한 문장·공백과 문장부호 포함 18자 이하, 명조 54px, 그림 바로 아래 자막을 유지했다.

소스: site/director.js 및 studio.js. 3D 붓 모델은 사용자가 지정한 project-pen/002의 pen-tools.js를 이 프로젝트용으로 수정했다. Three.js의 MIT 라이선스는 site/tool-render/vendor/LICENSE에 보존했다. 네 PNG 아틀라스를 실시간 Canvas에서 사용하며 3D 장면은 PNG 제작 때만 렌더링한다.

붓을 다시 만들려면 scripts/render_tool_frames.cjs 실행 후 scripts/build_director_assets.py를 실행한다. 두 스크립트 모두 MP4를 만들지 않는다. 플레이어 음원은 voice.wav에 4초 지연을 주고, 음악을 64초로 맞춰 해설 아래에서 음량을 조절한 voice-director.m4a와 music-director.m4a다.

검증: 1초 무그림 시작, 도입/인물/원본 단계, 되감기 재현성, 스밈 0/100 차이, 붓·스밈 저장, 모바일 가로 넘침 없음, 64초 음원, 다른 편의 기존 60초 동작 유지. 데스크톱 Chrome 도입 실재생 중앙값 약 59fps로 확인했다. 물리적 휴대전화 성능은 별도 측정하지 않았다.
