# 먹선·채색 순서 확인 — 2026-10-25

사용자는 처음 먹선이 먼저 아니냐고 물은 뒤 판단을 유보하고 조사를 요청했다. 조사 결과를 설명한 뒤 현재의 채색 후 먹선 정리 방식도 가능한지 확인했다. **이번 수정에서 painting.json, 붓질 PNG 및 카메라/자막/영상의 그림 순서는 변경하지 않는다.**

1. 한국민족문화대백과 「구륵법」: 윤곽을 선으로 먼저 그린 다음 안쪽을 채색하는 방법을 정의한다. 주로 화조·화훼의 기법 구분에 쓰인다는 문맥이므로 모든 풍속화의 실제 작업 순서라고 일반화하지 않는다.
   https://encykorea.aks.ac.kr/Article/E0005743
2. 같은 백과 「몰골법」: 윤곽선 없이 색채나 수묵으로 형태를 나타내는 방법. 색면을 먼저 만드는 방법도 있음을 보여 주지만, 이후 먹선으로 마무리하는 모든 그림을 몰골법이라고 부르지는 않는다.
   https://encykorea.aks.ac.kr/Article/E0018756
3. 한국민화학교 실제 기초 교육 과정: 연화도 과정에 본뜨기 → 밑색 칠하기 → 바림하기 → 마무리 윤곽선 긋기 → 마무리하기가 나온다. 처음 형태를 잡는 선과 채색 이후 마무리 선을 구분할 수 있는 직접 교육 자료다. 이 특정 앨범의 실제 제작 순서를 증명하는 자료는 아니다.
   https://www.tsom.kr/edu/lecture/applyBasicRead.do

판단: 현재 플레이어의 채색 → 먹선·세부 정리는 가능한 연출이다. 다만 원작가가 실제로 이 순서로 그렸다고 단정하지 않는다. 더 엄밀한 재현 대안으로 부분별 옅은 윤곽 → 담채 → 먹선 정리를 제안할 수 있으나, 사용자가 현재 방식도 맞는지 확인한 이 단계에서는 임의 적용하지 않는다.
