# 음악 편집 v8 — 2026-10-25

기존 Flow 음악은 초반 1초 단위 RMS가 약 -18.8~-35dB로 변화했고, 플레이어 음악 배율 0.35와 마스터 0.8이 더해져 약한 구간이 -40dB 이하까지 낮아졌다. 초반 영상 5초는 사용자가 요청한 음악 시작 시점 때문에 의도적인 대기다. 이를 로딩 문제라고 단정하지 않는다.

- `series/site/music-library.js`: 음악 전체 별도 재생, 지정한 음원 시점부터 재생, 재생 중인 위치를 영상의 음악 시작점으로 적용, 파형 클릭/키보드 선택, 곡 교체, 내 음악 파일 업로드.
- 영상 시작 시점 `musicStart`와 음원 내부 시작점 `musicOffset`을 구분한다.
- `scripts/music_library.py`: 음원별 큰 음량 차이를 줄인 뒤 약 -20 LUFS / -2dB TP로 변환하고 파형을 만든다. 보관한 Flow 생성 원본은 수정하지 않는다.
- 영상용 음악 크기 배율 0.55. 음원 전체 듣기는 별도 플레이어이며 영상과 동시에 소리가 겹치지 않게 서로 정지한다.
- 상태 표시에서 음악 대기 / 불러오는 중 / 재생 중 / 준비됨 / 오류를 구분한다. 미리 듣는 위치에서 바로 영상에 적용할 수 있다.
- 서버 `/api/series-music`은 목록 조회와 사용자 오디오 파일 업로드/변환을 지원한다. 업로드는 50MB 이하, 실제 오디오 스트림과 길이를 확인한다. 사용자 파일은 프로젝트에 남아 재접속 뒤 선택 가능하다.
- 새 목록을 5초마다 읽되 사용자가 고른 곡과 재생 위치를 바꾸지 않는다.
- Flow Music 세션: https://www.flowmusic.app/session/e283cc9f-2a87-4fb9-8b6c-93b4e58b2225
- 기존 곡 외 추가 4곡: 종이 위의 바람(고요), 윷판의 웃음(경쾌), 먹빛의 밤(긴장), 붓끝의 행진(웅장). 생성 결과는 각각 2분35초~3분이며, 요청한 90초와 차이가 있어 실제 길이를 표시한다. 가사 없음으로 요청한 AI 생성곡이다. 원본과 생성 메타데이터는 EP02/audio/flow-music 아래 보관하고, 변환본·파형은 series/music에 둔다.
