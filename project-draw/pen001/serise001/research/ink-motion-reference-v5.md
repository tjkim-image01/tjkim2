# 1화 도입 v5 관찰 기록 — 2026-10-25

- Danny Chen Art Studio, [How to avoid unwanted bleeding on Xuan paper](https://www.youtube.com/watch?v=vSkjszye4pc): 실제 영상을 내려받아 15초 간격 전체 프레임과 58~66초의 1초 간격 프레임을 직접 확인했다. 붓을 누르면 털이 휘어 접촉 면이 넓어지고, 들어 올리면 끝이 다시 좁아진다. 젖은 색이 화선지에 들어간 뒤 가장자리가 퍼진다.
- AR Bldr, [Ink Drops soaking into paper](https://vimeo.com/88028754): 실제 현미경 영상의 0.5~28초를 확인했다. 어두운 핵은 남고 시간이 지난 뒤 주변에 불규칙한 섬유 모양 테두리가 자란다. **이 영상의 종이는 Hammermill 카드지이며 화선지라고 소개하지 않는다.** 모세관 확산의 움직임만 참고했다.
- 참고 영상은 플레이어에 삽입하거나 음원을 추출하여 사용하지 않았다. 연구용 다운로드와 관찰 프레임은 /tmp에만 두었다.
- 새 도입은 빈 종이 1초 → 한 번 이어 쓰는 Latin `Tj` 2.5초 → 먹의 확산과 전체 서명 확인 → 인물 장면 전환, 총 5초이다.
- 획의 개별 위치에 붓이 닿은 시각과 압력을 기록한다. 지난 위치에서만 시간에 따라 바깥의 옅은 테두리·가는 섬유가 자라며, 아직 쓰지 않은 곳은 드러나지 않는다.
- 기존 4종×96자세에 더해 도입 대필은 4단계 압력×24각도, 96자세를 추가했다. 압력에 따라 털의 벌어짐·휨과 자루의 기울기를 획 두께에 맞춘다.
