# Pen001 · 드라이브 이미지 후보 조사

확인일: 2026-10-25 (Asia/Seoul)

사용자 공유 [Old Images26-1016](https://drive.google.com/drive/folders/1oQ55NzBeK_7ZttxFoazJD0Q16iz3fCXB)에서 판화 폴더를 우선 조사했다. 연도별 AP 폴더와 AP-NJ 폴더의 공개 초기 목록에서 중복 촬영을 줄인 대표 이미지 241개를 육안으로 살폈다. 초기 목록은 폴더당 최대 50개이므로 전체 드라이브 전수조사는 아니다.

기준은 J002처럼 그림을 단계적으로 완성하며 약 2분의 해설을 붙이기 좋은지, 설명 근거를 기관 자료에서 확보할 수 있는지다. 다음 작화 순서와 길이는 제작 제안이며 작가의 실제 제작 과정을 복원했다는 뜻은 아니다. 작품 도상을 식별한 것으로, 드라이브에 촬영된 물건의 진위·판본·제작연도까지 확인한 것은 아니다.

## 1. 앤디 워홀 · Flowers — 첫 제작 추천

- 위치: AP-Korea재고-Prints → AP2021.
- 대표 파일: `15.ANDY WARHOL FLOWERS 11.68.jpg`. [드라이브 이미지](https://drive.google.com/file/d/1WWLjy8aS4DV85rMga7-hl3DwNuJcdG0K/view).
- 같은 폴더에 11.64, 11.66, 11.72로 표시된 색상 변형 이미지도 있다. 파일명에 쓰인 11은 판화 목록의 로마 숫자 II를 뜻하는 것으로 보이지만, 촬영된 자료의 판본은 별도 확인 대상이다.
- 제안: 가벼운 윤곽 → 꽃 네 송이의 색면 → 풀과 잎의 선 → 같은 구도의 다른 배색 비교. 예상 2분~2분 30초.
- 해설: 사진을 평면적인 꽃의 형태로 바꾸는 과정, 실크스크린, 반복과 색의 변화.
- [워홀 미술관 교육 자료](https://www.warhol.org/lessons/silkscreen-printing/underpainting-and-photographic-silkscreen-printing/)에는 원본 사진, 밑칠과 최종 인쇄 단계, 영상 및 수업 자료가 있다. 색면을 칠한 뒤 사진 제판 이미지를 겹치는 방식을 설명한다. 드로잉 연출에 가장 직접적으로 도움이 된다.
- [교육용 이미지 PDF](https://www.warhol.org/wp-content/uploads/2018/04/Images-Lesson-4-Silkscreen-Printing.pdf), [MoMA의 1970년 Flowers 해설](https://www.moma.org/collection/works/64280), [Princeton 소장품 기록](https://artmuseum.princeton.edu/art/collections/objects/13641).
- 이미지 상태: 대표 파일은 작은 이미지의 픽셀 흔적이 보인다. 구조·배색 참조에는 적합하지만 원본 질감을 크게 확대해 그대로 드러내는 방식은 품질에 한계가 있다.

## 2. 폴 자쿨레 · Le bonze errant, Corée — 한국 소재 추천

- 위치: AP-Korea재고-Prints → AP2022.
- 파일: `APAC220126013.png`. [드라이브 이미지](https://drive.google.com/file/d/18XYkGrk0DvcebGJOvc6hox-57Mm9W1OO/view).
- 이미지 하단에 `Le Bonze Errant Corée`, `Paul Jacoulet`가 읽힌다. [NGV 소장품 기록](https://www.ngv.vic.gov.au/explore/collection/work/133160/)은 같은 제목을 The itinerant monk, Korea, 1948, 다색 목판화로 기록한다. 한국어 제목 ‘방랑하는 승려, 한국’은 여기서 붙인 번역이다.
- 제안: 갓 → 얼굴 → 지팡이 → 옷의 곡선 → 바닥과 배경 색면. 예상 2분 30초~3분.
- 해설: 인물의 자세와 선, 한국 복식, 프랑스 작가가 한국인을 목판화에 담은 배경.
- [국립중앙박물관의 자쿨레 전시 소개](https://www.museum.go.kr/MUSEUM/contents/M0202010000.do?exhiSpThemId=3411&listType=&menuId=current&schM=view), [플로리다대 도서관 한국 주제 전시](https://exhibits.uflib.ufl.edu/jacoulet/korea.html).
- 이미지 상태: 액자와 여백이 있고, 상세 묘사에 필요한 해상도가 높지 않다. 얼굴·손을 크게 보여주는 작화에는 더 선명한 참조가 필요하다.

## 3. 뱅크시 · Girl with Balloon 도상 — 짧은 감성 해설

- 위치: AP-Korea재고-Prints → AP2023.
- 파일: `APAC210803526 (1).jpg`. [드라이브 이미지](https://drive.google.com/file/d/1X7AeX_vLsEPqPfQmVFN_wQqDP8ff6XZ7/view).
- 제안: 소녀의 머리·옷 → 뻗은 팔 → 풍선 끈 → 붉은 하트. 예상 1분 30초~2분. 풍선을 마지막에 완성하는 연출이 명확하다.
- 해설: 흑백과 빨강의 대비, 손과 풍선 사이의 여백, 희망과 놓아줌이라는 감상 질문.
- [소더비의 작품 배경](https://www.sothebys.com/en/digital-catalogues/banksy-2022)은 2002년 런던 워털루 브리지 벽화에서 시작된 도상을 설명한다. ‘놓아줌’은 제안한 감상 관점이지 작가의 확정된 해답이 아니다.
- 이미지 상태: 흑백 경계가 비교적 선명하다. 사진에는 바깥 검은 바탕과 캔버스 표면이 함께 보인다.

## 4. 로버트 인디애나 · LOVE 도상 — 구조가 간단한 연습용

- 위치: AP-Korea재고-Prints → AP2023.
- 파일: `APAC230102001 (1).jpg`. [드라이브 이미지](https://drive.google.com/file/d/16aQG9CEWSqX93DyJexq0q4jkA3Zz16ep/view).
- 제안: 네 칸 구도 → L/V/E → 기울어진 O → 노랑·빨강·파랑·검정 색면. 예상 1분 30초~2분.
- 해설: 글자가 이미지가 되는 방식, O의 기울기, 단순한 글자의 강한 인상.
- [작가 재단 자료](https://www.robertindiana.com/artworks/artworks-items/love21), [휘트니미술관 감상 수업 자료](https://whitney.org/education/schools-educators/K-12/teaching-materials/activities/37). 이 자료의 소장 작품과 드라이브 이미지의 배색은 다르므로 도상의 배경 설명에 사용한다.
- 이미지 상태: 큰 형태와 종이 표면이 잘 보인다. 반듯한 글자와 색면의 제작 검증에 유리하다.

## 선택 의견

설명 자료와 색 변화까지 포함한 첫 작품에는 워홀의 꽃이 가장 유리하다. 한국적인 인물과 서사를 원하면 자쿨레, 짧고 감성적인 한 편이면 풍선을 든 소녀, 단순한 도형으로 제작 방식을 먼저 확인하려면 LOVE를 추천한다.

미리보기는 `shortlist.jpg`, 파일별 링크와 위치는 `candidates.json`, 개별 이미지는 `previews/`에 보관했다. 미리보기는 Google Drive가 제공하는 이미지이며 원본 파일 전체를 다운로드한 것으로 표기하지 않는다.
