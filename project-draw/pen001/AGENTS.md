# 드로잉 시리즈 사용자 확정 사항

- 현재 제작은 `serise001`의 첫 그림 1분 샘플이다. 3~5분 본편과 2·3번째 그림은 사용자 평가 뒤 진행한다.
- V1(2026-10-25)은 사용자가 거부했다. 거의 완성된 원본 사진에서 일부 먹선만 복원했기 때문이다. 이 버전을 승인된 기준으로 설명하지 않는다.
- 새 기준: 빈 종이 → 적은 양의 옅은 구도선 → 현재 붓질의 색면 → 먹선·표정. 밑그림만으로 전체 그림을 다 보여주거나 완성 사진을 초기 배경에 깔지 않는다.
- 붓질은 조금 빨라도 괜찮지만, 사용자가 그림이 실제로 만들어지는 과정을 볼 수 있어야 한다. 색면 안료에 나중의 검은 선을 섞지 않는다.
- 해설은 작가 소개를 짧게 하고, 무엇을 하는 장면인지·왜 그렸는지·당시 외국인이 조선의 무엇을 궁금해했는지에 집중한다. ‘미술 한류의 원조’는 언론의 비유적 표현으로 소개한다.
- 원본 `research/base.png`와 기존 영상은 보존한다.
- 사용자는 완성 MP4 외에 URL로 여는 중간 과정 드로잉 플레이어와 직접 수정하는 옵션을 요구했다. `serise001/web/index.html`은 실시간 Canvas 플레이어이고 `web/video.html`은 고정 MP4 화면이다.
- 플레이어 설정은 `serise001/config/player-settings.json`에 저장한다. 사용자가 저장한 옵션을 임의로 기본값으로 덮어쓰지 않는다. 이 옵션이 이미 출력한 MP4까지 변경했다고 설명하지 않는다.
- 2026-10-25: 사용자가 V2 제목과 그리기 속도를 좋다고 확인했다. 이를 유지한다. 완성 후 바깥 테두리를 정리한 원본으로 서서히 오버랩하는 V3를 요청했다.
- 영상과 해설에 `TJ KIM 컬렉션 소장품` 소장처 안내를 넣는다. 표준 발음 대본은 “이 작품은 티제이킴 컬렉션 소장품입니다.”.
- 배경음은 실제 공개 음원으로 교체했다. `serise001/audio/music/license.json`과 `research/music-license.md`를 따른다. 곡이 오래됐다는 이유만으로 녹음까지 자유 이용이라고 가정하지 않는다.
- 음악 출처 조건을 반드시 영상 안에 지킨다. 사용자는 품질을 해치지 않도록 **아래쪽 한 구석**에 적으라고 지정했다. V3는 왼쪽 아래 18px 3줄로 영상 전체에 곡명·저작자·출처·CC BY 4.0 및 URL·편집 내역을 표시한다. 큰 중앙 출처 카드로 바꾸지 않는다.
- 2026-10-25 후속 승인: 사용자가 앨범의 각 장면을 나눠 **새 숏 10편** 제작하고, 기존 삐라몰처럼 한곳에서 이어 볼 수 있는 홈페이지도 만들라고 명시했다. 질문 없이 진행을 요청했다. 이전 '추가 편은 평가 뒤' 제한은 이 승인으로 해제됐다. 기존 EP01은 보존하고 새 10편은 EP02~EP11로 제작한다.

- 새 10편 EP02~EP11과 모아보기는 `serise001/series/`에 있다. 홈페이지는 `/series/site/`, 연속 감상은 `watch.html`, 편별 실시간 수정은 `studio.html?ep=ep02`. 편별 설정은 `series/episodes/epXX/config/player-settings.json`이며 EP01 설정과 분리한다. 새 10편의 사용자 평가를 아직 승인으로 기록하지 않는다.

- 2026-10-25 후속 수정: 사용자는 홈페이지의 1화(윷놀이, 제작 파일 EP02)만 다시 만들어 검토하기로 했다. 순서는 **인물 한 명씩 얼굴·머리 → 몸·손 → 다리·아랫옷**, 모든 인물 뒤 **물건 → 배경**이다. 초기 전체 구도선과 선행 배경을 제거한다. 해당 편 자막은 나눔명조 Regular, 문구 전체를 차분히 보여 주며 타이핑·확대·바운스를 제거했다. 나머지 아홉 편과 별도 기존 EP01은 이 수정에서 변경하지 않았다.

- 2026-10-25 자막 최신 요청: 홈페이지 1화(EP02)는 **한 번에 한 문장·한 줄**, 공백·쉼표 등 문장부호 포함 **18자 이하**로 한다. 긴 해설은 뜻을 유지한 짧은 완결 문장으로 요약한다. 나눔명조 54px(이전 48px), 그림 바로 아래 y=1212에 배치하며 타이핑·확대 효과를 넣지 않는다. 1화만 적용했다.

- 최신 1화 v4 요청: **현재는 플레이어만 보여 주고 MP4를 만들지 않는다.** 인물을 그릴 때 크게 확대한다. 0~1초 정지, 1~3초 힘 있는 한 획의 붓끝을 클로즈업으로 따라가고 3~4초 구도를 전환한다. 도입 4초+기존 60초, 총 64초 플레이어이며 음성·자막도 도입에 맞춰 지연한다. 붓은 세필·중필·대필·평붓 4종, 각각 96자세의 조금 더 긴 붓을 사용한다. 약한 화선지 스밈과 강도 조절·저장 기능을 추가했다. site/director.js, episodes/ep02/episode.json의 player_director 설정을 따른다. 기존 MP4·일괄 ZIP은 v3이며 이 연출을 반영했다고 설명하지 않는다. 18자·한 문장·한 줄 명조 54px 자막을 유지한다.

- 최신 v5: 홈페이지 1화(EP02)의 도입은 0~1초 정지, 1~3.5초 **Latin Tj를 한 획으로 연결**해 쓰며 2.5초 추적, 이후 먹이 스미고 전체 서명을 보인 뒤 5초에서 인물 장면으로 전환한다. 총 65초 플레이어다. 실제 화선지 붓 시연과 현미경 잉크 확산 영상을 관찰했다. 도입용 압력 4단계×24각도 96자세를 추가했다.
- v5 음악: 사용자가 기존 경기아리랑을 거부하고 Flow Music 새 곡과 전통 타악 효과음을 요청했다. EP02 플레이어는 Flow Music에서 새로 생성한 `먹빛의 장단` 및 `먹빛 타악 효과음`만 사용한다. 기존 CC 음원이 없으므로 EP02의 기존 CC 출처 표시를 제거한다. 다른 편에서 기존 CC 음원을 사용하는 경우 그 출처는 유지한다. 생성 기록·원본·편집점·약관 링크는 `series/episodes/ep02/audio/flow-music/`에 보존한다. AI 생성곡을 퍼블릭 도메인으로 단정하지 않는다. **MP4 제작 금지는 계속 유지**하며 기존 10편 MP4와 ZIP은 변경하지 않는다.

- v6 최신: 그림 작업 영역은 **1080×1920 화면의 y=0~1440(위쪽 75%)**, 제목·한 줄 자막·소장처는 아래 25%에 배치한다. EP02 플레이어 자막 y=1470이며 MP4용 기존 좌표를 바꾸지 않는다. 새 Tj는 가는 진입·힘 있는 T 가로획·굵기 변화·연결된 j·긴 마무리 곡선의 캘리그래피다. 화선지 섬유 높이·미세 조명·젖은 먹의 시간별 거칠기를 WebGL 재질 셰이더로 표현한다. 번짐은 이미 쓴 획에서만 계속 자라며 되감기가 가능하다.
- v6 소리: 1~3.39초 북 연타, Tj 완성 3.5초에 짧은 장구 테소리와 비슷한 효과 한 번. 북/중간 타악음은 기존 Flow 생성 원본에서 편집, 테소리는 직접 모달 합성한 효과이며 실제 녹음으로 주장하지 않는다. 효과음은 영상 시점에 고정하고 음악과 분리한다. 기본 음악 시작은 5초. 에디터의 `musicStart`(영상 시점), `musicOffset`(음원 시작 위치), `effectsEnabled`, `effectsVolume`은 즉시 반영·저장·불러오기 가능하다. `현재 위치로`와 테소리 미리듣기를 제공한다. 여전히 플레이어만 수정하고 MP4는 만들지 않는다.

- v6 도입은 먹이 스미는 모습을 충분히 보이도록 6초로 조정했다. 3.5초 서명 완성 → 4.15초 전체 서명 → 5.6초까지 스밈 유지 → 6초 인물 전환. 음성·자막도 6초 도입에 맞추며 총 66초다. 음악 시작 기본값 5초와 직접 변경 기능은 유지한다.

- 2026-10-25 v7: 사용자가 색/먹선 순서를 물었다가 정정을 철회하고 조사를 요청했다. 구륵법·몰골법과 실제 민화 교육 과정을 확인했다(`serise001/research/painting-order-check.md`). **채색 뒤 먹선·세부를 정리하는 현재 연출도 가능한 방식**이라고 설명했다. 원작가 실제 순서가 확인된 것으로 주장하지 않는다. 이번에는 그림 순서와 painting.json을 변경하지 않는다.
- v7 소리: 기존 단발 테소리를 **징 울림**으로 교체하고 북 연타·완성 징·중간 타악음을 별도 트랙/음량으로 분리한다. 북은 낮추고 중간 효과음은 침묵 제외 300ms 에너지로 보정했다. 북 기본 75%(최대 200%), 징·중간 타악 기본 100%(최대 300%). Web Audio GainNode와 피크 제어를 통해 100% 이상이 실제 증폭되게 한다. 징은 기존 Flow 금속성 잔향과 직접 합성한 금속 공명을 섞은 효과이며 실제 징 녹음으로 주장하지 않는다. 음악 시작 위치와 66초 영상 시점은 유지하고 MP4는 변경하지 않는다.

- v8/v9 최신 음악 요청: 사용자가 음악 전체 듣기, 원하는 음원 지점부터 듣기, 곡/파일 교체, 서로 다른 분위기 4곡 추가를 요구했다. `site/music-library.js`, `/api/series-music`, `series/music/tracks/`가 음악 목록·파형·전체 미리듣기·지정 위치 듣기·듣는 위치를 영상에 사용·파일 업로드를 담당한다. `musicTrack`, `musicStart`(영상에서 시작할 때), `musicOffset`(음원의 시작점)은 별개이며 저장된다. 영상과 미리듣기가 겹치지 않게 서로 멈춘다. 생성/업로드 곡은 5초마다 목록에 반영하며 이미 선택한 곡과 위치는 유지한다.
- 기존곡 외 Flow Music에서 실제 생성한 4곡: `종이 위의 바람`(고요), `윷판의 웃음`(경쾌), `먹빛의 밤`(긴장), `붓끝의 행진`(웅장). 각각 2분34초~3분 원본/메타데이터 보관. 재생본은 앞 무음 정리와 음량 균형 보정을 하고 원본은 보존한다. 음원 초반/중간의 강약과 기존 낮은 배율 때문에 작게 들릴 수 있었고, 영상 첫 5초는 음악 시작 설정에 따른 대기다. 이를 로딩 오류로 단정하지 않는다. 파형은 16kHz 전대역에 가까운 분석으로 만든다.
- 최신 징 철회: 사용자가 완성 순간과 **48초의 징 효과음 제거**를 명시했다. 두 곳의 징을 제거했다. 사용자가 설명한 악기는 앞·좌우에 큰 북 3개가 둘러선 구성이라고 답했다. 삼고무형 세 북의 느낌으로 짧은 `둥·다·둥` 맺음을 만든다. `court-finish-v9.m4a`는 새 Flow 북 효과음에서 편집한 AI 생성 음향이며 조선시대 특정 궁중악기의 실연 녹음이나 역사적 복원으로 주장하지 않는다. 완성 음량은 새 `finishVolume`(최대 300%)로 조절하며 기존 `jingVolume`을 새 북에 임의 승계하지 않는다. 중간 효과음은 `accents-v9.m4a`, 48초 이후 안료/음성 외 별도 효과음 없음. 배경곡 자체의 악기 편성을 제거한 것으로 주장하지 않는다.

- 자막 최신 v10 요청: 홈페이지 1화(EP02) 플레이어 자막을 y1470→1374로 96px 올리고 기본 크기54→60px로 한 단계 키웠다. 75% 작업 영역과 한 줄·공백/문장부호 포함18자 제한, 차분한 명조는 유지한다. MP4용 caption_layout과 영상은 보존하고 player_director의 caption_top/caption_font_size를 적용한다.

- 최신 v11: 사용자가 인트로를 제외한 **모든 별도 효과음 제거**를 명시했다. EP02 플레이어에서 중간 타악 트랙 자체와 조절 UI를 제거했다. 20.4/34.2/48초 포함 본문에는 별도 효과음 없음. 인트로 북 연타와 3.5초 북 맺음, 해설·배경음악·선택한 음악 설정 및 60px/y1374 자막은 유지한다. 오래된 중간 효과음 파일은 자료로 보존하되 플레이어가 로드/재생하지 않는다.
