# 티제이 김 컬렉션 · 삐라 상점 — 웹사이트 기획서 (tj001 · 샘플)

작성: 2026-10-16. 사용자 요청: "tj002(삐라 영상)의 느낌으로, 영상이 재생되고, 보다가 물건도 사는 밝고 유쾌한 정적 쇼핑몰 샘플. 캐릭터 포함. 상품 상세는 md 파일."

## 1. 한 줄 정의

**"영상 보다가 삐라 사는 가게."** 태진과 옥자 이모가 삐라 이야기를 들려주는 숏·롱 영상 11편이 입구이고, 영상에 나온 실물 삐라(티제이 김 컬렉션 86점)가 바로 옆에서 팔린다. 레트로 팝 포스터 톤(원색·하프톤·굵은 먹선·효과음 글자)을 영상에서 그대로 가져온다.

## 2. 왜 이렇게 만드나

| 기존 상점(shop2) | 이번 샘플(tj001) |
|---|---|
| 6,300점 카탈로그, 검색 우선, 경매 하우스 격조 | **한 주제(삐라) 86점**, 영상 우선, 예능 포스터 톤 |
| 백엔드(FastAPI)+DB, 문의 접수 API | **정적 사이트**(빌드 결과물만 배포), 상품 상세 = md 파일, 장바구니는 브라우저 저장소 |
| 상품 → 설명 → 문의 | **영상 → 등장 물건 → 담기 → 구매 문의**(메일/복사) |

이유: 삐라는 설명 없이는 안 팔리는 물건이다. 설명을 글 대신 2인 대화 영상으로 하고, 영상 안에 나온 바로 그 장을 "이거 살 수 있어요"로 잇는다. 정적 사이트라 서버 없이 Vercel·GitHub Pages에 그대로 올라가고, 상품은 md 한 장씩 추가하면 된다.

## 3. 시청자·구매자

- 1차: 50~60대. "삐라 주우면 공책 줬다"에 반응하는 세대. 글자 크게, 버튼 크게, 한 화면에 한 가지.
- 2차: 20~40대 수집·역사 취향. 영어 삐라·원화·분석표 같은 희귀성에 반응.
- 구매는 고가 1점물이라 **실결제 없음**. 담아서 "구매 문의"를 보내면 담당자가 가격·배송을 안내(shop2와 같은 원칙).

- 글꼴: 제목·효과음 **Black Han Sans**, 숫자 **Bagel Fat One**, 본문 **Pretendard / 나눔스퀘어라운드**, 손글씨 **나눔펜**.
- 캐릭터: 태진(수집가·파랑)·옥자 이모(빨강) 각 4포즈(기본·놀람·웃음·가리킴) 누끼. 페이지마다 둘이 말풍선으로 안내한다. 마우스를 올리거나 스크롤하면 포즈가 바뀐다.

- 금지: 그라데이션, 사진 실사 배경, 얇은 회색 글자, 작은 글씨.

## 5. 사이트 구조 (정적 · 해시 라우팅)

```
/                홈 — 히어로(캐릭터 + 말풍선 + 롱폼 자동재생) → 에피소드 11편 → 이 영상의 물건 → 주제별 진열
/watch/:ep       영상 — 세로 쇼츠(9:16) 또는 롱폼(16:9) 플레이어 + "이 영상에 나온 삐라" 카드 + 다음 편
/shop            상품 — 에피소드·발행 주체·언어 칩 필터, 카드 격자(썸네일·제목·연도·가격·담기)
/shop/:code      상품 상세 — 큰 이미지(앞·뒤·분석표) + md 본문 + "이 삐라가 나오는 영상" + 담기/바로 문의
/cart            장바구니 — 브라우저 저장소. 수량·삭제 → "구매 문의하기"
/inquiry         구매 문의 — 이름·연락처·메모 입력 → 메일 앱 열기(mailto) + 내용 복사. 서버 없음
/about           컬렉션 소개 · 캐릭터 소개 · 구매 방법 · 출처
```

## 6. 화면 설계

### 6-1. 홈
1. **히어로**(하늘색 선버스트): 왼쪽 태진, 오른쪽 옥자 이모(놀람 포즈). 가운데 큰 제목 "삐라 주워서 공책 받아 봤어?" + 말풍선 "영상 보다가, 마음에 들면 담아 가세요". 아래 롱폼이 무음 자동재생(클릭하면 소리). 삐라 썸네일이 천천히 떨어지는 배경.
2. **에피소드 띠**(노랑): 쇼츠 10편 + 롱폼 1편 카드. 카드 = 표지 + 제목 + 길이. 가로 스크롤.
3. **이 영상의 물건**(크림): 영상 11편에 등장한 삐라 24점. "영상에 나온 그 장" 도장.
4. **주제별 진열**(민트/핑크/빨강 색면 교차): 안전보장증서 · 집 생각나게 하는 삐라 · 북한이 미군에게 · 중국어 삐라 · 1945 · 분석표가 붙은 삐라.
5. **옥자 이모의 한마디**(먹색): "요즘은 주워도 공책 안 줘. 대신 여기서 사." + 구매 방법 3단계.

### 6-2. 영상 페이지
- 쇼츠: 가운데 9:16 플레이어(최대 높이 80vh), 왼쪽 캐릭터, 오른쪽 **"이 영상에 나온 삐라"** 세로 카드 열. 영상이 끝나면 다음 편 자동.
- 롱폼: 16:9 플레이어 + 아래 챕터(파트) 버튼(클릭하면 해당 시각으로) + 챕터마다 등장 물건.
- 재생 중 특정 시각에 "지금 화면의 삐라" 칩이 뜬다(에피소드 데이터의 `cues`).

### 6-3. 상품 목록
- 상단 칩: 전체 / 영상에 나온 것 / 유엔군→북한군 / 유엔군→중공군 / 북한·중공군→미군 / 1945 / 원화·분석표.
- 카드: 삐라 썸네일(크림 테두리·먹 그림자, 살짝 기울임) + 제목(한글 짧게) + 연도·발행 + 가격(USD) + **담기** 버튼(도장 모양).
- 정렬: 영상 등장 우선 → 연도.

### 6-4. 상품 상세 (md)
- 왼쪽: 이미지 갤러리(앞·뒤·분석표·세트). 클릭하면 확대.
- 오른쪽: 제목, 연도·발행·크기·수량, 가격, 담기/바로 문의, "이 삐라가 나오는 영상" 버튼(해당 시각으로 이동).
- 아래: md 본문 — 무슨 삐라인가 / 뒷면·분석표 / 영상에서 한 말(대사 인용) / 상태·주의.
- 캐릭터: 태진이 모서리에서 "뒷면도 보세요" 말풍선.

### 6-5. 장바구니·문의
- 장바구니: 카드 목록 + 합계(USD) + "구매 문의하기".
- 문의: 이름·연락처·메모 + 담긴 목록이 자동으로 메일 본문이 된다. "메일 앱으로 보내기" / "내용 복사". 실결제·서버 없음을 명시.

## 7. 데이터 규칙

### 7-1. 상품 md (`site/src/content/products/<Item No.>.md`)

```markdown
---
code: APKC210526397C
title: 안전보장증서 (빨강 · 한국어)
title_en: Safe Conduct Pass (Korean, red)
year: 1950
maker: 극동사령부 (Far East Command)
size: 12 x 20 cm
qty: 1
price_usd: 100
group: safe            # safe · home · enemy · chinese · 1945 · art · analysis · etc
episodes: [S, D, long] # 등장 영상
featured: true         # 영상에 나온 그 장
images: [APKC210526397C_1.jpg, APKC210526397C_2.jpg]
condition: 접힘 자국, 전반적으로 양호
---
## 무슨 삐라인가
...
## 영상에서
> 태진: "이거 들고 오면 안전 보장. 제일 많이 뿌린 종류예요." (D편)
```

- 원본: tjkim DB `items`(읽기 전용) + 재고 시트 `판매가 (US$)`. 원가·매입처·보관 위치는 넣지 않는다(shop2 공개 원칙).
- 이미지: Drive 스캔(1600px)을 1200px로 줄여 `public/items/`, 카드용 420px은 `public/thumbs/`.
- 가격이 없으면 "문의"로 표시.

### 7-2. 에피소드 (`site/src/data/episodes.ts`)
id · 제목 · 파일 · 길이 · 세로/가로 · 등장 상품 코드 · 큐(초 → 상품 코드) · 챕터(롱폼).

### 7-3. 영상 파일
원본(1080p, 40~160MB)은 그대로 두고, 웹용으로 720p·H.264·faststart로 줄여 `public/videos/`에 둔다(편당 5~15MB).

## 8. 기술

- Vite + React + TypeScript(admin001·shop2와 같은 스택), `react-router` HashRouter(정적 호스팅에서 새로고침 안전).
- md: 빌드 때 `import.meta.glob`으로 읽어 front matter를 직접 파싱, 본문은 `marked`로 HTML.
- 상태: 장바구니만 `localStorage`.
- 글꼴: Google Fonts(Black Han Sans·Bagel Fat One·Jua·Nanum Pen Script) + Pretendard CDN.
- 배포: `npm run build` → `dist/`를 Vercel 또는 GitHub Pages. 서버·DB 없음.
- 폴더:
  ```
  proejct-web/tj001/
  ├── 01.기획/           기획서(이 문서) · 화면 설계
  └── site/              Vite 프로젝트
      ├── public/videos|items|thumbs|chars
      └── src/content/products/*.md · data/episodes.ts · pages · components
  ```
